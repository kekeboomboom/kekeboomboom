## About Me

我是 Keboom。

相比“程序员”这个标签，我更愿意把自己理解为一个站在技术和传播交叉点上的人:

- 我写代码，也写内容
- 我做产品，也研究传播
- 我喜欢 AI，但我更在意 AI 怎样真正进入普通人的工作和生活

我很认同 Naval 提到的一些关键词：

- leverage
- specific knowledge
- long-term compound interest

所以我想做的，不只是工具本身。
我更想做的是把技术能力、内容表达和个人品牌连成一条线，让科技普惠大众。

## My Thesis

我长期关注这几个方向：

- AI Agent 如何真正进入真实工作流
- 科技内容如何从“看起来很懂”变成“真的能帮人用起来”
- 自媒体和技术产品能不能形成正向飞轮
- 一个人如何借助软件和内容建立自己的杠杆

如果要用一句话概括我现在的方向，那就是：

> 用技术构建产品，用内容建立认知，用长期主义积累个人品牌。
